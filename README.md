# Compiladores

Cómo se traduce un lenguaje a código que ejecuta la máquina: análisis léxico y sintáctico LL y LR, análisis semántico, representación intermedia y SSA, optimizaciones, asignación de registros, WebAssembly, recolección de basura, JIT y LLVM, compilando Ceiba, el lenguaje diseñado en Lenguajes de programación.

**Ver en línea:** https://aaramirez.github.io/compiladores/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
